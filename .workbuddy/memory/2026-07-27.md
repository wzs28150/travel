## 第二轮修复与增强（同日）
- **重要坑**：tdesign-mobile-vue 的 `t-date-time-picker` 和 `t-picker` 都是**纯内联面板，没有 visible 属性**，必须用 `<t-popup v-model="show" placement="bottom">` 包裹，并在 @confirm/@cancel 里手动关闭 popup。之前用 v-model:visible 导致选择器直接平铺在页面里（半截）。
- **重要坑**：`t-cell` 的 `leftIcon` 是 Function/slot 类型，传字符串 `left-icon="user-1"` 不渲染。必须用 `#leftIcon` 插槽放 `<t-icon>`。Mine 页图标已改插槽。
- 滚动修复：`#app` 的 `overflow:hidden` 会裁剪内容导致无法滚动，改为 `overflow-x:hidden`。
- tab-bar 宽度修复：AppTabBar 用 `left:50%;transform:translateX(-50%);width:100%;max-width:480px` + `:deep(.t-tab-bar){width:100%}`，删除 global.css 里冲突的 .t-tab-bar 覆盖。
- **新增出行天气**：src/utils/weather.js，用 Open-Meteo 免费 API（无需 key，Asia/Shanghai 时区）按行程日期区间取每日天气码+高低温，失败/无数据用确定性伪随机兜底（mock 标"参考"，真实标"实时预报"）。城市坐标从 cities.js 模糊匹配 destination。TravelDetail hero 下方横向滚动天气卡片。
- tdesign 图标名坑：无 `cloudy`（用 `cloud`）、无 `cloud-1`、无 `swap-1`。用前先在 tdesign-icons-vue-next/esm/manifest.js 里 grep 校验。
- vite build 在本沙箱清空旧 dist 时会报 trash 错误（非代码问题），先 `rm -rf dist` 再 build 即可。
